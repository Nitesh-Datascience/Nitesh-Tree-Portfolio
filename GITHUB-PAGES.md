# Put this project on GitHub Pages

1. Open your repository: **Nitesh-Datascience/Nitesh-Tree-Portfolio**.
2. The website files are already uploaded to the repository root.
3. Confirm that `index.html`, `styles.css`, `projects.js`, `app.js`, and the `assets` folder are present in the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose **main** and **/(root)**, then select **Save**.
7. When GitHub finishes deploying, open the website link shown on the Pages screen.

Example address for the suggested repository: `https://Nitesh-Datascience.github.io/Nitesh-Tree-Portfolio/`.

This address becomes available after you enable GitHub Pages and its deployment succeeds. Uploading the files alone does not enable GitHub Pages.

To update the website later, edit or replace the same files in the repository and commit the changes. Do not upload the project ZIP as your website.

Reference: [GitHub Pages official quickstart](https://docs.github.com/en/pages/quickstart).
